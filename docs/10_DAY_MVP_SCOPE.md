# 5. DO NOT BUILD FOR MVP

Do not spend prototype time on:

* Full production payment gateway
* Full logistics platform
* Blockchain
* Building our own LLM
* Training a foundation model
* Native Android and iOS separately
* Full KYC platform
* Production Amazon integration
* Production Flipkart integration
* Production ONDC integration unless official access is available
* Complex enterprise admin
* Large social networking features
* Unnecessary microservices
* Over-engineered recommendation systems

# 13. SUCCESS CRITERIA

MVP is successful when:

An artisan can create a product using photo + voice.

AI can generate a useful draft catalogue.

AI can ask missing-information questions.

Artisan can answer and edit.

AI can suggest a price.

Artisan can approve.

Product becomes published.

Customer can find the real product using natural language.

Customer can view artisan story.

Customer can place a demo order.

The entire flow works in one stable application.
